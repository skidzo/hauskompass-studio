# Renovation Decision Register

Renovation decisions should be recorded before they become implicit assumptions in geometry, assessment panels, or exports.

## Decision Fields

Each decision should record:

- title and decision area
- description
- alternatives
- selected option, if any
- related objects
- evidence dependencies
- assumption dependencies
- risks
- status
- decision date, if selected

## Initial Decision Areas

- roof insulation
- PV placement
- roof extension
- wall removal
- structural preservation
- heating
- moisture control
- facade
- basement
- indoor comfort
- budget
- permitting

## Decision Discipline

Rejected or deferred options should remain visible in the register. This prevents repeated exploration of already discarded ideas and keeps the reasoning traceable.
