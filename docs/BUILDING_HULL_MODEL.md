# Building Hull Model

The first model is a building-hull baseline, not a digital twin.

LoD2 and manual sketches can provide:

```txt
- approximate footprint
- outer roof surfaces
- wall candidates
- terrain relation
- surrounding geometry context
```

They cannot provide:

```txt
- structural proof
- construction-ready dimensions
- actual roof timber layout
- material condition
- moisture condition
- permit-ready planning detail
```

Every derived value needs a source, confidence level and manual-verification flag where relevant.
