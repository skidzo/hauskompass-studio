# Data Sources

The v0.1 application inventories likely sources before it imports anything.

```txt
- Manual local coordinates
- Nominatim / OpenStreetMap
- Photon / Komoot
- basemap.de / BKG
- LoD2 Bayern / LDBV
- DGM1 Bayern / LDBV
- Energie-Atlas Bayern
- PVGIS / EU JRC
- DWD TRY
- Copernicus ERA5 / ERA5-Land
- Bayerischer Denkmal-Atlas
- UmweltAtlas Bayern
```

Geocoder results are not building truth. LoD2 is a useful first outer-hull baseline, but it is not BIM and does not describe the real roof construction, purlins, rafters, structural condition, hidden moisture or reusable timber.
