# First Sprint

## Goal

Create a local Vite + React + TypeScript application that represents the house assessment project, protects private data, and shows the first dashboard for data inventory, building hull status and missing measurements.

## Scope

```txt
- domain model
- data inventory seed
- mock building hull
- dashboard
- map placeholder
- 3D viewer placeholder
- roof surface table
- missing measurements panel
- docs and privacy guardrails
```

## Definition of Done

```txt
[ ] npm install works
[ ] npm run dev works
[ ] app renders locally
[ ] no real address is committed
[ ] docs explain public geodata limitations
[ ] dashboard shows source and confidence status
```

## Non-Goals

```txt
- BIM
- structural engineering
- construction-ready dimensions
- permit automation
- cost estimation
- cloud backend
- user accounts
- AI autonomy
```
