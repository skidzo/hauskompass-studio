# Overview

This project builds a private evidence-based baseline model for an existing house before renovation. The first technical milestone is a 3D building hull derived from public geodata and corrected with private measurements.

The system is designed to support renovation decisions by making sources, assumptions and uncertainties visible. It should answer four questions before planning work becomes expensive:

```txt
What do we know?
Where did it come from?
How confident are we?
What must be measured before decisions?
```

The first version is a local technical dashboard, not a cloud product.
