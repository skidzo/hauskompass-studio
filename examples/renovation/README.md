# Building Assessment Example Package

This package is fictional placeholder data only. It demonstrates the first separated building/asset information model:

- building elements hold geometry/context/lifecycle links;
- asset types hold product/system specifications;
- asset instances hold planned or installed object state;
- measurements reference asset instances;
- evidence documents reference building elements and asset instances;
- requirements reference known objects and can later be validated.
- assessment findings link defects, photos, requirements and decisions in a BCF-inspired internal issue model.
- decisions link back to findings when an unresolved issue blocks or constrains a renovation choice.

The examples intentionally avoid private address data, exact coordinates and real product commitments.
